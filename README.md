# MagicVol · 10 档媒体音量

把系统媒体音量从默认的 16 档改成 **10 档**（0–9）：0 档静音，1–9 档可以按「占系统最大音量的百分比」自由设置。

> **实测环境：HONOR BRT-AN00 / MagicOS 11.0.0.115（Android 17, SDK 37）**。
> 本模块只在这一台机器的一个系统版本上验证过；其他 ROM、其他 Android 版本请自行体验，
> 很可能因为 AudioService 实现不同而完全不生效（尤其非 Honor / 非 MagicOS 的机型）。

## 功能

- 媒体音量 10 档：音量键每按一次正好走一档，0 档静音（没有声音）。
- 1–9 档可自定义：拖动滑杆设置每一档占系统最大音量的百分比（1–100%）。
- 上限跟随系统：第 9 档 100% 就是系统最大音量，**任何档位都不会超过它**。
- 低档不会高于高档：保存时自动把递减的数值拉平，避免出现「第 3 档比第 4 档响」。
- 按递增快速填档：填入起始值与递增值，一键铺满 9 档（例：起始 2、递增 3 → 2/5/8/11/…/26%）。
- 方案：把当前 9 档存成命名方案，可随时切换、重命名、删除（方案只是 UI 层数据，不影响生效逻辑）。
- 「应用这个音量设置」：保存当前设置并立刻把当前档位重新下发一次（系统在档位没变时会跳过下发）。
- 「恢复默认档位」：一键回到 11/22/33/44/56/67/78/89/100%。
- 调试日志开关（默认关闭，界面上最底下）：排查问题时打开，模块日志里才会出现详细记录。
- **只改媒体音量**：铃声、通知、通话、闹钟都不受影响。

## 安装要求

| 项目 | 要求 |
|---|---|
| 系统 | Android 10+（minSdk 29），**仅在 MagicOS 11 / Android 17 实测** |
| 框架 | LSPosed（libxposed API 102+） |
| 作用域 | 只需要勾选「**系统框架**」（`system`），不要勾 App |

安装后到 LSPosed 里启用模块、勾选系统框架，然后**重启手机**（钩子在 `system_server` 启动时注入，不重启不会生效）。

## 使用

1. 打开 MagicVol，给 1–9 档拖好百分比（或用「按递增快速填档位」一键铺满）。
2. 按音量键调音量，就是 0–9 共 10 档；第 9 档 = 系统最大。
3. 改完百分比最多 1 秒内对所有新音量调节生效；如果某个 App 正停在旧音量上，点一下「应用这个音量设置」强制刷新。
4. 界面底部状态行会显示「当前 0–9 共 10 档」，说明模块已生效；显示「当前 0–16（模块未生效）」说明还没重启或作用域没勾对。

## 原理（简述）

1. 在 `AudioService.createStreamStates()` 进入时把静态数组 `MAX_STREAM_VOLUME[3]` 从 160 改成 90 —— `VolumeStreamState` 随即按 `90 × 10 = 900` 定内部刻度，对外 API、音量键步长、持久化键、系统音量面板全部跟着变成 0–9。
2. 在 `AudioSystem.setStreamVolumeIndexAS()` 上把档位索引（0–90）按用户百分比翻译成真正的 HAL 索引（0–90，其中 90 是 AudioPolicyManager 的满刻度，超过会被截断成满音量）。
3. 设置通过一个只读 `ContentProvider` 从 App 传给 `system_server`（钩子进程读不到 App 的私有目录）；1 秒 TTL 缓存。

## 构建

不需要 Gradle，脚本直接调 `javac` / `d8` / `aapt2`：

```sh
./build.sh          # 产出 build/MagicVol-unsigned.apk（未签名）
./build.sh --sign   # 额外用 tools/debug.keystore 签一个测试包（仅供自测）
```

## 发布签名

当前 Release 里的 APK 使用 **Android Debug 测试密钥**签名（证书 SHA-256 `9f9a6007…e4ebb82220`），
只是为了让大家能装上体验；之后的版本会换成作者的正式密钥。**签名变了就必须先卸载再安装**。

## 已知限制

- 只处理媒体流（`STREAM_MUSIC`）。其它流保持系统原样。
- 系统「安全音量」阈值（90）与本模块的满刻度（90）重合：插耳机时超过安全音量的提示行为仍由系统决定。
- 音量百分比是「按 AudioPolicyManager 的音量曲线线性换算」的近似值，不同设备的响度曲线不同，人耳感受不会完全线性。
